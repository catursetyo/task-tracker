# Task Tracker Kuliah

Repositori ini berisi implementasi program Task Tracker yang dipisahkan menjadi dua versi sesuai modul penugasan:
- task-tracker-v1: Implementasi DOM Manipulation, Form Handling, Event Delegation, Filter, dan LocalStorage.
- task-tracker-v2: Implementasi Asynchronous JavaScript, Fetch API terintegrasi Mock REST API, Promise.all, penanganan status loading/error, dan optimistic update.

## Struktur Direktori

- task-tracker-v1/
  - index.html
  - style.css
  - app.js
- task-tracker-v2/
  - index.html
  - style.css
  - app.js
  - mock-api.js

## Log Penggunaan AI

- Model: Google Antigravity (Gemini 3.8 Flash)
- Ringkasan Interaksi:
  1. Pembuatan kode dasar Task Tracker v1 mencakup manipulasi DOM, validasi form, event delegation pada daftar tugas, filter status, dan localStorage.
  2. Pengembangan Task Tracker v2 dengan migrasi ke REST API menggunakan Fetch API, helper fungsi api(), pemanggilan data paralel dengan Promise.all, penanganan status UI, serta pembaruan dan penghapusan data dengan optimistic update.
  3. Pemisahan struktur program menjadi dua program mandiri (task-tracker-v1 dan task-tracker-v2) sesuai spesifikasi modul masing-masing tanpa menyertakan komentar pada source code program.
